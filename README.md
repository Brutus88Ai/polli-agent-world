# Ecosystem 0 - AI Agents Left Alone in a Terrarium World

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**Ecosystem 0** is an interactive, autonomous 2D terrarium simulation inspired by the research paper *"Is this machine playing?"*. Without benchmarks, tasks, deadlines, or objectives, artificial intelligence agents wander, play, inspect monoliths, create sand patterns, and engage in idle philosophical contemplation.

Built for the **Pollinations Quest #19177: [QUEST] An app or game about AI agents left alone in a world**.

## Features

- **Emergent Play**: Autonomous agents roam with flocking and idle wandering dynamics.
- **Consciousness Inspector**: Click any agent to inspect its internal monologue, curiosity index, solitude tendency, and playful impulses.
- **Interactive Environment**: Spawn obsidian monoliths, drop glowing light orbs, and cycle through day/night cosmic epochs.
- **Zero-Pollen Guarantee**: Comes with an offline simulation engine and pre-computed contemplations (0 Pollen spent) alongside `<polli-connect>` Bring Your Own Pollen (BYOP) integration for live Pollinations LLM models.
- **Pollinations Integration**: Direct integration with `https://gen.pollinations.ai/v1/chat/completions`.
